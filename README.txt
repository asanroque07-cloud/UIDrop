UIVisualBuilder
Make your first UI in just a minute.

Open index.html in a browser to use the designer.
Projects are saved in your browser.
Use Save design > Folder to download the website you make as a ZIP.

Welcome screen
  The first time you open UIVisualBuilder, an animated welcome plays (the drop falls into the logo), then asks your name. Type it and press Continue (or Enter).
  Your name is saved in your browser and shown as "Hi, Name" on the projects page. Click Change name to enter a different one. Esc closes the screen once a name is saved.

Shortcuts
  Ctrl/Cmd+Z            Undo (each page has its own history)
  Ctrl/Cmd+Shift+Z / Y  Redo
  Arrow keys            Nudge the selected shape (hold Shift for 10px)
  Delete                Remove the selected shape
  Esc                   Close a popup or deselect (or stop Play)
  Ctrl/Cmd+Enter        Play: test your website

Working form controls (Insert menu)
  Buttons    Button, Outline, Submit, Reset, Round button. Pick "When clicked": go to a page, open a web address, send the form, clear the form, or show a message.
  Input      Text field, Email, Password, Number, Phone, Date, Search, Text area, File upload, Color picker, Slider.
  Selection  Dropdown, Radio group, Checklist, Checkbox, Switch.
  To choose what can be selected, select a Dropdown / Radio group / Checklist and type the choices in "What to select" (separate with commas).
  Then pick the "Selected by default" choice. Give every field a Field name and mark it Required if you like.
  Press Play (or open the exported page): typing, picking, ticking, sliding and uploading all work. Submit checks required fields and shows what was sent.

Resize: select any shape, image or file, then drag the square handles on its corners or sides with the mouse (or finger).
  Corners keep an image's proportions; hold Shift to stretch it freely (for other shapes, Shift keeps proportions).
  The Width / Height boxes in the side panel still work and stay in sync.

Animation after an action: select a Button, Link, Dropdown, Radio group, Checklist, Checkbox, Switch or Navbar, then choose an effect from Entrance (Fade, Zoom, Slide, Rotate or Flip), Emphasis (Pulse, Bounce, Heartbeat, Rubber band, Jello or Tada), or Attention (Shake, Wobble, Swing, Spin or Flash).
  Tune duration, start delay, easing and repeat count, then use "Preview animation" to try it in the designer. Choose "Animate which shape" to animate a different shape.
  Set "Hidden until an animation shows it" on a shape to reveal it from a button. "Always animate (loop)" includes Float, Pulse, Bounce, Wiggle, Sway, Heartbeat, Spin and Glow.
Buttons: quickly insert Soft, Ghost or Gradient presets, or set any button to Solid, Outline, Soft, Ghost or Gradient style. Preview Lift, Grow, Glow, Shine or Press hover feedback in the editor and Play mode. Exported pages respect reduced-motion preferences.

Menus (Insert > Menus):
  Menu bar        A navbar with Home / About / Contact links.
  Sidebar menu    A hamburger button that opens a sidebar with links and a Close button.
  Dropdown menu   A "Menu" button that opens a list of items under it.
  Menu button, Dropdown button and Sidebar panel are also there as single pieces.
  Any button or link can use "When clicked > Show or hide a shape" and pick the shape. Shapes in one group open and close together.
  Shapes marked "Hidden until an animation shows it" start hidden (they look faded in the designer). Pick an animation under "When it opens, animate".
  On phones the sidebar slides over the page and dropdown items open in the column.

Responsive: open Page settings > "Responsive (whole website)".
  Rearrange into a column on phones: adds a CSS media query (max-width 640px) that stacks the shapes top to bottom.
  Keep the layout, shrink to fit: everything scales down with the screen.   Fixed size: no scaling.
  In Play, pick a phone size from the size menu to test it.

Pages: use the tabs above the canvas. "+ Add page" and "Page settings" open popups.
Size: pick a screen size from the dropdown above the canvas. Phone and tablet projects also have a Rotate button (portrait or landscape).
Small screens: tap "+ Insert" to add shapes; tap a shape to edit it in the bottom sheet.

Play: press the green Play button (or Ctrl/Cmd+Enter) to run your website in a live test window.
  Links and buttons that go to a page work, so you can click through every page. Use Back, Restart and the page menu at the top.
  Fields can be typed in and animations run. "All devices" projects have a screen size menu and Rotate button to test every screen.
  Press Stop or Esc to go back to the designer. Your design is not changed by testing.
